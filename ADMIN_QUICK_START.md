## **Deploy in 3 Steps**

### **Step 1: Push to GitHub (3 min)**

```bash
mkdir brandsintel-admin
cd brandsintel-admin

# Copy all the files I created
# Into this folder

git init
git add .
git commit -m "Admin dashboard"
git remote add origin https://github.com/YOUR_USERNAME/brandsintel-admin.git
git push -u origin main
```

### **Step 2: Deploy to Vercel (3 min)**

1. Go to https://vercel.com/
2. Click "Add New" → "Project"
3. Import your GitHub repo
4. Add environment variable:
   ```
   REACT_APP_API_BASE=https://brandsintel-backend.onrender.com
   ```
5. Click "Deploy"

### **Step 3: Login (1 min)**

Wait 2 minutes for deployment to complete.

Go to: https://brandsintel-admin.vercel.app

Password: `BrandsIntel2024`
